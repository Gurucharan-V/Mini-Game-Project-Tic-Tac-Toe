# C++ Tic Tac Toe Game
A simple 2-player console game written in C++ for Task 4 of the Thiranex internship.
## How to Play
- Player 1 is `X` and Player 2 is `O`.
- Choose a slot from 1 to 9 corresponding to the board layout.
- The game automatically checks for horizontal, vertical, and diagonal wins, as well as draws.
- Includes a prompt to replay as many rounds as you want.
## Run Locally
```bash
g++ main.cpp -o tictactoe
./tictactoe
